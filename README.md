# Personeros - Sistema de Asistencia Electoral

Sistema de registro y monitoreo de asistencia de personeros electorales.

## Funcionalidades

- **Login seguro** con diseño moderno dark mode 3D
- **Dashboard** con estadísticas en tiempo real
- **Registro de personeros** con código único, nombre, DNI, partido político, colegio y mesa
- **Confirmación de asistencia** (PRESENTE / AUSENTE / PENDIENTE)
- **PWA** - Se puede instalar en el celular como app
- **Detección automática** - Versión móvil o escritorio según el dispositivo
- **Colegios de Chulucanas, Piura** pre-cargados

## Instalación

```bash
pip install -r requirements.txt
python app.py
```

Accede a: `http://localhost:5050`
